# MDNote使用說明

本說明依上方選單順序介紹 MDNote 的選單與畫面。在文件中加入標題、清單、表格的方法，請參閱**說明 → MD檔案撰寫方法**。

## 1. 檔案

| 選單 | 快速鍵 | 說明 |
| --- | --- | --- |
| 繼續先前的工作階段 | | 開啟後，關閉尚未儲存的文件時不會詢問，下次開啟 MDNote 時將直接原樣重新開啟其內容。預設為關閉。 |
| 最近的檔案 | | 重新開啟最近開過的文件。 |
| 要復原的文件… | | 復原或刪除未儲存即關閉的文件。 |
| ![New](guide-new.png) 新增 | Ctrl+N, Ctrl+T | 開啟新文件。 |
| ![Open](guide-open.png) 開啟… | Ctrl+O | 開啟 MD、TXT 檔案。 |
| 指定編碼開啟… | | 文字顯示亂碼時，選擇編碼重新開啟。 |
| ![儲存](guide-save.png) 儲存 | Ctrl+S | 儲存目前的文件。 |
| 另存新檔… | Ctrl+Shift+S | 選擇新名稱與編碼後儲存。若將檔案類型選為 **HTML 檔案 (*.html)**，只會另外產生 .html 檔案，目前開啟的文件保持不變。 |
| 列印… | Ctrl+P | 列印文件。 |
| 結束 | Alt+F4 | 僅關閉目前的視窗，其他視窗保持不變。 |

- 將檔案拖放至視窗，或在檔案總管中連按兩下也能開啟。
- 將透過**另存新檔…**產生的 HTML 檔案儲存在與文件相同的資料夾中，圖片仍可正常顯示。公式在 HTML 中會保留為文字。
- 若其他程式修改或刪除了已開啟的檔案，MDNote 會詢問是否重新載入，或提示檔案已不存在。儲存到被其他程式修改過的檔案時，會先詢問是否覆寫。
- 尚未儲存的內容會在啟動應用程式時詢問是否復原，並在您從**要復原的文件…**（復原選取項目、刪除選取項目、稍後）手動復原或刪除前一直保留。
- **另存新檔**的編碼可從 UTF-8、UTF-8(BOM)、UTF-16 LE、UTF-16 BE、ANSI 中選擇；以 Shift JIS、GBK、Big5、Windows-1252、UTF-32 LE/BE 開啟的文件也可選擇維持目前編碼。ANSI 為配合 Windows 語言的編碼：韓文為 CP949，簡體中文為 GBK，繁體中文為 Big5，日文為 Shift JIS，英文為 Windows-1252。開啟非 UTF-8 檔案時也會以此編碼讀取。若有所選編碼無法表示的字元，系統會提示改用 UTF-8 儲存。
- 切換 MD 與 TXT 模式導致與副檔名不符時，儲存時會建議符合新模式的副檔名，避免覆寫原檔案。
- 關閉尚未儲存的文件時，可選擇**儲存、捨棄、取消**。因 Windows 關機等原因而同時關閉多個視窗時，若按下**取消**便會停止關閉其餘視窗。

## 2. 編輯

| 選單 | 快速鍵 | 說明 |
| --- | --- | --- |
| ![edit](guide-btn-edit.zh-TW.png) 開始 / 結束編輯 | Ctrl+E | 在閱讀畫面與編輯畫面之間切換。 |
| 一律以編輯模式開啟 | | 開啟後，文件一打開即可直接編輯。 |
| ![txt](guide-btn-txt.png) TXT 模式 | | 將 MD 文件轉為純文字或還原。 |
| 新文件預設使用 TXT 模式 | | 開啟後，新文件會以 TXT 開始。 |
| 復原 / 重做 | Ctrl+Z / Ctrl+Y | 取消或重新套用剛才的編輯。連續輸入的文字（含倒退鍵 Backspace）會一次復原；在移動游標、按 Delete、貼上、剪下、執行命令、切換焦點或切換文件後輸入的文字，則會分為新的步驟。 |
| 全選 / 複製 / 剪下 | Ctrl+A / Ctrl+C / Ctrl+X | 選取全部內容，或複製、剪下選取的文字。 |
| 貼上 | Ctrl+V | 保留格式貼上。 |
| 貼上純文字 | Ctrl+Shift+V | 僅貼上文字。 |
| 插入圖片… | Ctrl+Shift+I | 插入圖片。 |
| ![find](guide-find.png) 尋找… | Ctrl+F | 尋找文字。 |
| ![replace](guide-replace.png) 取代… | Ctrl+H | 尋找並取代文字。 |

- **一律以編輯模式開啟**為開啟狀態（預設）時，文件會直接以編輯畫面開啟；關閉後則以**閱讀**畫面開啟。在基本模式的編輯畫面中，會隱藏 `#`、`**` 等符號，直接以套用格式後的樣貌編輯。在**即時模式**（檢視選單）中，編輯畫面裡只有游標所在行與選取的行會顯示符號。
- 切換為 **TXT 模式**時，符號會被移除、僅保留可見文字，表格欄位之間則以 Tab 分隔。將 TXT 切回 MD 時，原本已寫下的符號不會突然變成格式。若誤切，可按 Ctrl+Z 復原。
- **貼上**會保留粗體、斜體、刪除線、連結與另外指定的文字色彩。在 TXT 模式中則一律只貼上純文字。
- **插入圖片**：用 Ctrl+V 貼上複製的圖片、貼上或拖放圖片檔案，或透過「插入圖片…」選擇後，圖片會立即顯示。儲存時會在文件旁建立同名資料夾（如 `筆記.md` → `筆記\`），僅將文件中保留的圖片移入並更新連結。儲存前刪除的圖片不會存入，已在該資料夾中的圖片也不會重複複製。另存新檔時，會將文件使用的圖片複製到新名稱的資料夾中。程式碼區塊或行內程式碼中的圖片連結會原樣保留。若開啟的其他文件也在使用同一張圖片，則會複製而非移動。尚未儲存的圖片會暫存於 `文件\MDNote\images`，超過 7 天且未被任何文件使用的圖片會在啟動 MDNote 時移至資源回收筒。
- 將圖片檔拖放至編輯視窗也能插入圖片。
- 游標位於程式碼區塊內時貼上圖片，圖片會放在程式碼區塊正下方的一行。
- 尋找、取代只要再按一次相同的快速鍵即可關閉。
- 開啟區分大小寫按鈕旁的 `.*` 按鈕（**使用正規表示式**），即可依模式尋找。取代時可用 `$1` 等指代群組。預設為關閉。

## 3. 檢視

| 選單 | 快速鍵 | 說明 |
| --- | --- | --- |
| 在新分頁中開啟 | | 開啟時檔案會以新分頁打開，關閉時則以新視窗打開。 |
| 自動換行 | | 依視窗寬度自動換行顯示。 |
| Markdown 即時預覽 | | 開啟時，在編輯畫面中僅將游標所在行與選取的行顯示為原始文字（含符號）。關閉時則為基本模式。 |
| 放大文字 / 縮小文字 | Ctrl++ / Ctrl+- | 也可使用 Ctrl+滾輪。 |
| 重設文字大小 | Ctrl+0 | 回到原本的大小。 |
| 行距 | | 可從 100、125、150、200% 與自訂中選擇。 |
| 字型與大小… | | 設定預設字型與大小。 |
| 預設文字色彩… / 重設預設文字色彩 | | 設定或還原整份文件的預設色彩。 |
| ![dark](guide-btn-dark.png) 深色模式 | | 切換為深色畫面。 |
| 專注模式 | | 可在段落、行、關閉中選擇。段落只清楚顯示游標所在的段落，行只清楚顯示游標所在的行，其餘部分變淡。預設為關閉。 |
| 打字機模式 | | 開啟後，正在輸入的行會一直保持在視窗中間。預設為關閉。 |

- 關閉**在新分頁中開啟**的瞬間，目前已開啟的分頁會各自拆分為新視窗。
- **自動換行**不會在檔案中加入換行符號。關閉時，長行會以水平捲軸檢視。
- **基本模式**會將整份文件以套用格式後的樣貌顯示，游標所在行也會隱藏 `**`、`#` 等符號。初次執行時即為此模式。
- **即時檢視**可由檢視 → **Markdown 即時預覽**開啟，開啟後在編輯畫面中僅將游標所在行與選取的行顯示為原始文字（含符號）（在閱讀畫面中則一律只顯示套用格式後的樣貌），方便直接看著符號修改。初始狀態為關閉（基本模式），變更後的模式在下次執行時仍會記住。
- **行距**的初始預設值為 150%，同時適用於 MD 與 TXT。
- 格式工具列的文字色彩僅套用於選取的文字，與**預設文字色彩**分開運作。
- 檢視設定僅改變畫面顯示，不會影響檔案內容。

## 8. 輸入時的動作

| 位置 | 按鍵 | 動作 |
| --- | --- | --- |
| 行首 | `-`、`*`、`+`、`1.` 後加一個半形空白或 Tab | 立即變成清單。（全形空白會視為一般文字，不會變成清單。） |
| 行首 | 輸入 `` ``` ``（或附上語言名稱的 `` ```python ``）後按 Enter | 產生含結尾行的程式碼區塊，游標位於其中。 |
| 清單 | Tab / Shift+Tab | 縮排或凸排一層。 |
| 空白清單項目 | Enter | 在同一層新增一個空白項目。 |
| 清單項目開頭 | Backspace | 按一下刪除清單標記，按兩下連同縮排一併刪除。 |
| 有文字的核取方塊行 | Enter | 新增一行核取方塊。 |
| 粗體、斜體、刪除線、行內程式碼內 | Enter | 在基本模式與即時模式中，換行後兩行都會繼續維持原本的格式。 |
| 表格儲存格內 | Home / End | 移至該儲存格的開頭／結尾。 |
| 表格儲存格內 | ↑ / ↓ | 在儲存格內移動行；在儲存格最後一行時，會移至下一列的同一欄。 |
| 表格內 | Tab / Shift+Tab | 移至下一格或上一格，並選取該儲存格的文字。在最後一列的最後一格按 Tab，會在下方新增一列。若在選取文字或儲存格的狀態下按下，不會刪除文字，而是直接移至選取範圍結尾的下一格（Shift+Tab 則為選取範圍前的上一格）。 |
| 緊鄰表格前方或後方 | Enter | 在表格外新增空白行。 |
| 表格內 | Ctrl+] / Ctrl+[ | 將整個表格縮排至正上方的清單項目內，或移出清單外。 |

- 若不想繼續輸入待辦清單，在新產生的空白核取方塊行按 **Backspace** 即可刪除方塊。
- 在閱讀與編輯畫面中，都可以點選方塊切換完成狀態。切換後須按 **Ctrl+S** 儲存才會寫入檔案。
- 在表格中選取部分儲存格並刪除或輸入文字時，分隔線（`|`）與表格外觀會保持不變，只會清除或替換所選儲存格內的內容。不過，若選取整個表格或按 Ctrl+A 全選後刪除，就會像一般文字一樣將整個表格刪除。
- 句子中的 `$E=mc^2$`，以及單獨成行的 `$$ … $$`（```` ```math ```` 程式碼區塊也一樣）會顯示為公式。游標移到公式上時會顯示原文，可直接修改。表格儲存格內也一樣。像 `$5 and $10` 這樣的內容仍是一般文字。沒有輸入公式的按鈕。

表格的第二列（`---` 分隔線列）無法在編輯畫面中直接修改。欄位對齊方式請由表格工具列的對齊按鈕（或原始碼畫面）變更。

表格左右兩端外側的 `|` 即使省略，也會辨識為同一個表格。在儲存格內輸入 `|` 時，系統會自動儲存為 `\|` 以免表格跑掉；而在 `程式碼` 內輸入的 `|` 則會原樣保留，不會分割儲存格。

- 若正上方不是清單，表格工具列的縮排按鈕會呈淡化狀態。

## 9. 分頁與視窗

| 快速鍵 | 動作 |
| --- | --- |
| Ctrl+W | 關閉分頁 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一個分頁 / 上一個分頁 |

- 若有空白視窗，將不會另開新視窗，而是直接在該視窗中開啟。
- 視窗位置、大小，以及檢視、編輯、語言設定，在重新啟動或更新應用程式後仍會保留。

## 10. 已知限制

- 在基本模式的編輯畫面中，無法使用 **Alt+拖曳**進行矩形選取。在即時模式或 ![原始碼](guide-btn-source.zh-TW.png) **原始碼**畫面中則可使用。
