MDNote インストール前のご案内

• Windows 10/11 x64 および .NET Framework 4.8 以降で使用します。
• このコンピューターのすべてのユーザー用にインストールし、管理者権限を要求します。
• 既定のインストール先は C:\Program Files\MDNote です。Windows の Program Files の場所が異なる場合は、その場所を使用します。
• 次の画面でインストール パスを選択します。新しい専用フォルダーを推奨します。
• アップデート インストールの前に、MDNote の文書を保存し、ウィンドウをすべて閉じてください。
• プログラムとともに、ソース・ビルド スクリプト・使い方・サンプル文書がインストールされます。
• インストール後、.md ファイルの「プログラムから開く」で MDNote を選択できます。既定のアプリは強制的に変更しません。
• フォント・文字サイズ・行間・文字色・ダーク モード・言語などの画面設定は、ユーザー アカウントごとに LocalAppData\MDNote\settings.xml に別途保存され、アップデートしても維持されます。
• Windows の「設定」 > 「アプリ」 > 「インストールされているアプリ」または「コントロール パネル」 > 「プログラムと機能」から「MDNote」をアンインストールできます。
• アンインストール時、インストールしたファイル・ショートカット・アプリ登録を消去します。アンインストールを実行したアカウントの画面設定の削除は個別に選択できます。他のアカウントの設定は削除しません。
• ご自身で作成したり別途追加したりした文書は削除しません。残っているユーザー ファイルがある場合、インストール フォルダーも残ります。
• デジタル署名は適用していません。Windows が確認されていない発行元として表示する場合があります。
