MDNote 설치 전 안내

• Windows 10/11 x64 및 .NET Framework 4.8 이상에서 사용합니다.
• 이 컴퓨터의 모든 사용자용으로 설치하며 관리자 권한을 요청합니다.
• 기본 설치 위치는 C:\Program Files\MDNote입니다. Windows의 Program Files 위치가 다르면 해당 위치를 사용합니다.
• 다음 화면에서 설치 경로를 선택합니다. 새 전용 폴더를 권장합니다.
• 업데이트 설치 전 MDNote의 문서를 저장하고 창을 모두 닫아 주세요.
• 프로그램과 함께 소스·빌드 스크립트·사용법·예제 문서가 설치됩니다.
• 설치 후 .md 파일의 연결 프로그램에서 MDNote를 선택할 수 있습니다. 기본 앱은 강제로 바꾸지 않습니다.
• 글꼴·글자 크기·줄 간격·글자색·다크 모드·언어 같은 화면 설정은 사용자 계정마다 LocalAppData\MDNote\settings.xml에 따로 저장하며, 업데이트해도 유지됩니다.
• Windows 설정 → 앱 → 설치된 앱 또는 제어판 → 프로그램 및 기능에서 'MDNote'를 제거할 수 있습니다.
• 제거 시 설치한 파일·바로가기·앱 등록을 지웁니다. 제거를 실행한 계정의 화면 설정 삭제는 별도로 선택할 수 있습니다. 다른 계정의 설정은 삭제하지 않습니다.
• 직접 작성하거나 별도로 추가한 문서는 제거하지 않습니다. 남은 사용자 파일이 있으면 설치 폴더도 남습니다.
• 디지털 서명은 적용하지 않았습니다. Windows가 확인되지 않은 게시자로 표시할 수 있습니다.
• MDNote는 GNU General Public License v3.0으로 배포합니다. LICENSE를 참고해 주세요.

안내를 확인했다면 '계속'을 눌러 주세요.
