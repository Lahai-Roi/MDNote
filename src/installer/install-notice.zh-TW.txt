MDNote 安裝前須知

• 於 Windows 10/11 x64 及 .NET Framework 4.8 或更新版本中使用。
• 為這部電腦的所有使用者安裝，並要求系統管理員權限。
• 預設安裝位置為 C:\Program Files\MDNote。若 Windows 的 Program Files 位置不同，則使用該位置。
• 在下一個畫面中選擇安裝路徑。建議使用新的專用資料夾。
• 更新安裝前，請儲存 MDNote 的文件並關閉所有視窗。
• 隨程式一併安裝原始碼、建置指令碼、使用方法及範例文件。
• 安裝後，可在 .md 檔案的「開啟方式」中選擇 MDNote。不會強制變更預設應用程式。
• 字型、字型大小、行距、文字顏色、深色模式、語言等顯示設定會依每個使用者帳戶分開儲存於 LocalAppData\MDNote\settings.xml 中，即使更新也會保留。
• 可從 Windows「設定」 > 「應用程式」 > 「已安裝的應用程式」或「控制台」 > 「程式和功能」中解除安裝「MDNote」。
• 解除安裝時會清除已安裝的檔案、捷徑及應用程式註冊。可另外選擇是否刪除執行解除安裝之帳戶的顯示設定。不會刪除其他帳戶的設定。
• 不會移除您自行編寫或另外新增的文件。若有剩餘的使用者檔案，安裝資料夾也會保留。
• 未套用數位簽章。Windows 可能會顯示為未經驗證的發行者。
