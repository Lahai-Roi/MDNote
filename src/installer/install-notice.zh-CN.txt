MDNote 安装前须知

• 在 Windows 10/11 x64 及 .NET Framework 4.8 或更高版本中使用。
• 为这台电脑的所有用户安装，并请求管理员权限。
• 默认安装位置为 C:\Program Files\MDNote。如果 Windows 的 Program Files 位置不同，则使用相应位置。
• 在下一画面中选择安装路径。建议使用新的专用文件夹。
• 更新安装前，请保存 MDNote 的文档并关闭所有窗口。
• 随程序一起安装源代码、构建脚本、使用方法和示例文档。
• 安装后，可在 .md 文件的“打开方式”中选择 MDNote。不会强制更改默认应用。
• 字体、字号、行距、文字颜色、深色模式、语言等显示设置按每个用户账户单独保存在 LocalAppData\MDNote\settings.xml 中，即使更新也会保留。
• 可在 Windows“设置” > “应用” > “已安装的应用”或“控制面板” > “程序和功能”中卸载“MDNote”。
• 卸载时将清除已安装的文件、快捷方式和应用注册。可单独选择是否删除执行卸载的账户的显示设置。不会删除其他账户的设置。
• 不会移除您自己编写或另行添加的文档。如果存在剩余的用户文件，安装文件夹也会保留。
• 未应用数字签名。Windows 可能会显示为未验证的发布者。
• MDNote 按 GNU General Public License v3.0 发布。请参阅 LICENSE。

确认以上须知后，请点击“继续”。
