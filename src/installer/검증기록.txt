MDNote 설치 패키지 1.9.1
2026-10-17 (Asia/Seoul)

시험 빌드에서 통과:
- 새 전용 설치 폴더 생성, 공백/한글이 있는 사용자 지정 경로
- 다른 파일이 있는 폴더로의 설치 거부 및 해당 파일 보존
- 사용 중인 실행 파일에 대한 덮어쓰기 방지
- Windows 앱 등록 키, 버전, 경로, 따옴표가 있는 제거 명령
- 소스 및 인계 자료 설치
- 동일 경로 재설치
- 설치 폴더에 추가한 사용자 MD 문서의 제거 후 보존
- 설치 파일/시험 레지스트리/ProgID 제거
- 남은 파일이 없는 설치 폴더 제거

시험 등록은 별도 HKCU 이름을 사용했으며 시험 후 제거했습니다.
배포 빌드는 관리자 권한, Program Files 64비트 기본 경로, HKLM 64비트 공용 등록과 공용 시작 메뉴를 사용합니다.
현재 개발 PC에서 시험했으며 Windows 10/11 각각의 별도 VM 실기 검사는 하지 않았습니다.
기존 앱 EXE는 변경하지 않았습니다. 배포 설치 EXE의 최종 해시와 Defender 결과는 outputs의 설치파일-검증기록.txt에 기록합니다.

1.9.1: 공백/한글 경로, 점유 폴더 거부, 사용 중 파일 보호, 앱 등록, 재설치, 문서 보존, 제거 검사 통과. 완료 화면의 바로가기 체크박스는 NSIS Modern UI 표준 콜백을 사용합니다. 시험 빌드에서는 시스템 바로가기 생성을 생략했습니다. 실제 제품 설치를 강제로 적용하지 않았습니다.
