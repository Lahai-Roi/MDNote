# MDNoteの使い方

MDNoteのメニューと画面を上部のメニュー順に説明します。文書に見出し・リスト・表を入れる方法は **ヘルプ → MDファイルの書き方** で確認できます。

## 1. ファイル

| メニュー | ショートカット | 説明 |
| --- | --- | --- |
| 前のセッションを続行 | | オンにすると、未保存の文書を閉じるときに確認せず、次回MDNoteを開くときにその内容をそのまま再び開きます。初期設定はオフです。 |
| ![New](guide-new.png) 新規作成 | Ctrl+N, Ctrl+T | 新規文書を開きます。 |
| ![Open](guide-open.png) 開く… | Ctrl+O | MD・TXTファイルを開きます。 |
| エンコードを指定して開く… | | 文字化けするときに文字コードを選んで開き直します。 |
| 復元する文書… | | 保存せずに閉じた文書を復元または削除します。 |
| 最近使ったファイル | | 最近開いた文書をもう一度開きます。 |
| ![保存](guide-save.png) 保存 | Ctrl+S | 現在の文書を保存します。 |
| 名前を付けて保存… | Ctrl+Shift+S | 新しい名前と文字コードを選んで保存します。 |
| 印刷… | Ctrl+P | 文書を印刷します。 |
| 終了 | Alt+F4 | 現在のウィンドウだけを閉じます。他のウィンドウはそのまま残ります。 |

- ファイルをウィンドウにドラッグ＆ドロップするか、エクスプローラーでダブルクリックしても開けます。
- 未保存の文章はアプリ起動時に復元するか確認され、**復元する文書…**（選択して復元・選択して削除・後で）から直接復元または削除するまで保管されます。
- **名前を付けて保存**の文字コードは、UTF-8・UTF-8(BOM)・UTF-16 LE・UTF-16 BE・ANSI(CP949)から選ぶか、Shift JIS・GBK・Big5・Windows-1252・UTF-32 LE/BEで開いた文書では現在の文字コードの維持を選べます。CP949で表現できない文字がある場合は、UTF-8で保存するよう案内します。
- MDとTXTモードを切り替えてファイル拡張子と合わなくなった場合、保存時に現在のモードに合う拡張子を提案し、元のファイルを上書きしないようにします。
- 未保存の文書を閉じるときは、**保存・破棄・キャンセル**から選びます。Windowsの終了などで複数のウィンドウが同時に閉じられるときに**キャンセル**を押すと、残りのウィンドウを閉じる操作を中断します。

## 2. 編集

| メニュー | ショートカット | 説明 |
| --- | --- | --- |
| ![edit](guide-btn-edit.ja.png) 編集の開始 / 終了 | Ctrl+E | 閲覧画面と編集画面を切り替えます。 |
| 常に編集モードで開く | | オンにすると、文書を開いてすぐ編集できます。 |
| ![txt](guide-btn-txt.png) TXTモード | | MD文書を通常のテキストに変換、または元に戻します。 |
| 新規文書をTXTモードで開く | | オンにすると、新規文書がTXTで始まります。 |
| 元に戻す / やり直す | Ctrl+Z / Ctrl+Y | 直前の編集を取り消すか、やり直します。続けて入力した文字（Backspaceを含む）は一度に元に戻り、カーソル移動・Delete・貼り付け・切り取り・コマンド実行・フォーカス移動・文書切り替えの後に入力した文字は新しい段階に分かれます。 |
| すべて選択 / コピー / 切り取り | Ctrl+A / Ctrl+C / Ctrl+X | 全体を選択するか、選択した文字をコピー・切り取りします。 |
| 貼り付け | Ctrl+V | 書式を保ったまま貼り付けます。 |
| 書式なしで貼り付け | Ctrl+Shift+V | 文字だけを貼り付けます。 |
| 画像を挿入… | Ctrl+Shift+I | 画像を入れます。 |
| ![find](guide-find.png) 検索… | Ctrl+F | 文字を検索します。 |
| ![replace](guide-replace.png) 置換… | Ctrl+H | 文字を検索して置換します。 |

- 文書は**常に編集モードで開く**がオン（初期設定）のときはすぐ編集画面で開き、オフにすると**閲覧**画面で開きます。基本モードの編集画面では `#` や `**` などの記号が隠れたまま、書式が適用された見た目で編集します。**ライブモード**（表示メニュー）では、編集画面でカーソルのある行と選択した行だけ記号が表示されます。
- **TXTモード**に切り替えると記号は消えて表示されている文字だけが残り、表はセルの間をTabで区切ります。TXTをMDに戻しても、すでに書かれている記号が急に書式に変わることはありません。誤って切り替えた場合はCtrl+Zで元に戻せます。
- **貼り付け**は、太字・斜体・取り消し線・リンクと個別に指定した文字色を維持します。TXTモードでは常に文字だけを貼り付けます。
- **画像の挿入**: コピーした画像をCtrl+Vで貼り付けるか、画像ファイルを貼り付け・ドラッグ＆ドロップするか、「画像を挿入…」で選択すると画面にすぐ表示されます。保存時に文書の隣に同じ名前のフォルダー（例: `メモ.md` → `メモ\`）を作成し、文書に残っている画像だけを移動してリンクを更新します。保存前に削除した画像は含まれず、すでにそのフォルダー内にある画像は再コピーされません。名前を付けて保存すると、使用中の画像を新しい名前のフォルダーにコピーします。
- 画像ファイルを編集画面にドラッグ＆ドロップしても画像が入ります。
- 検索・置換は、同じショートカットをもう一度押すと閉じます。

## 3. 表示

| メニュー | ショートカット | 説明 |
| --- | --- | --- |
| 新しいタブで開く | | オンで新しいタブ、オフで新しいウィンドウにファイルを開きます。 |
| 右端で折り返す | | ウィンドウ幅に合わせて行を折り返して表示します。 |
| 文字を拡大 / 文字を縮小 | Ctrl++ / Ctrl+- | Ctrl+ホイールでも操作できます。 |
| 文字サイズをリセット | Ctrl+0 | 元のサイズに戻します。 |
| フォントとサイズ… | | 既定のフォントとサイズを設定します。 |
| 既定の文字色… / 既定の文字色をリセット | | 文書全体の既定の色を設定、または元に戻します。 |
| ![dark](guide-btn-dark.png) ダークモード | | 暗い配色の画面に切り替えます。 |
| 行間 | | 100・125・150・200%とカスタムから選びます。 |
| Markdown ライブプレビュー | | オンにすると、編集画面でカーソルのある行と選択した行だけを原文（記号を含む）で表示します。オフにすると基本モードです。 |

- **新しいタブで開く**をオフにした瞬間、開いていたタブはそれぞれ新しいウィンドウに分かれます。
- **右端で折り返す**はファイル自体に改行を入れません。オフにすると長い行を横スクロールで表示します。
- 書式ツールバーの文字色は選択した文字だけに適用される書式のため、**既定の文字色**とは別に動作します。
- **行間**の初期設定は150%で、MDとTXTの両方に適用されます。
- **基本モード**では文書全体が書式適用後の見た目で表示され、カーソルのある行も `**`・`#` などの記号を隠します。初回起動時はこのモードです。
- **ライブビュー**は、表示 → **Markdown ライブプレビュー**をオンにすると、編集画面でカーソルのある行と選択した行だけを原文（記号を含む）で表示します（閲覧画面では常に書式が適用された見た目だけが表示されます）。記号を直接見ながら直したいときに便利です。初期状態ではオフ（基本モード）になっており、切り替えたモードは次回起動時も記憶されます。
- 表示設定は画面の見た目を変えるだけで、ファイルの内容には影響しません。

## 7. ツールバーと画面

| ツール | 位置 | 説明 |
| --- | --- | --- |
| 書式ツールバー | メニューの下（編集中） | 見出し・文字飾り・リスト・チェック・引用・コード・リンク・画像・表のボタンがあります。 |
| ![ソース](guide-btn-source.ja.png) ソース | 書式ツールバーの右端 | 記号やHTMLタグがそのまま見えるソースを編集します。 |
| ![txt](guide-btn-txt.png) TXT | 上部 | 編集 → **TXTモード**と同じです。 |
| ![outline](guide-outline.png) アウトライン | 右上 | 見出しの一覧を表示し、押すとその見出しへ移動します。 |
| 表ツールバー | 表の中にカーソルを置いたとき | 左・中央・右揃え、行を追加・行を削除、列を追加・列を削除、表を削除、下に段落を追加、インデント増減のボタンがあります。列の揃え位置は2行目（`---`）を直接書き換えず、この揃えボタンで変更します。 |

- **ソース**をオフにすると、書式が適用された画面に戻ります。
- TXTモードでは、行番号付きの通常のテキスト編集を行います。
- アウトラインはH1～H6の表示付きで並び、本文との境界線をドラッグして幅を変えられます。

## 8. 入力時の動作

| 位置 | キー | 動作 |
| --- | --- | --- |
| 行頭 | `-`, `*`, `+`, `1.` の後に半角スペース1つまたはTab | そのままリストになります。（全角スペースは通常の文字として扱われ、リストにはなりません。） |
| リスト | Tab / Shift+Tab | 1段階インデントを増やす／減らします。 |
| 空のリスト項目 | Enter | 同じ階層に空の項目がもう1つ作られます。 |
| リスト項目の先頭 | Backspace | 1回でリスト記号、2回でインデントまで消えます。 |
| 文字のあるチェックボックス行 | Enter | 新しいチェックボックス行が作られます。 |
| 太字・斜体・取り消し線・インラインコードの中 | Enter | 基本モードとライブモードのどちらも、改行しても両方の行で書式がそのまま引き継がれます。 |
| 表のセル内 | Home / End | そのセルの先頭／末尾へ移動します。 |
| 表のセル内 | ↑ / ↓ | セル内で行を移動し、セルの最終行からは下の行の同じ列へ移ります。 |
| 表の中 | Tab / Shift+Tab | 次のセルまたは前のセルへ移動し、そのセルの文字を選択します。最終行の最後のセルでTabを押すと、下に新しい行が追加されます。文字やセルを選択したまま押すと、文字を消さずに選択範囲の次のセル（Shift+Tabは前のセル）へ移動だけします。 |
| 表の直前または直後 | Enter | 表の外に空行が作られます。 |
| 表の中 | Ctrl+] / Ctrl+[ | 表全体を直上のリスト項目の中に入れるか、外に出します。 |

- チェックリストを終了するには、新しくできた空のチェックボックス行で**Backspace**を押してボックスを消します。
- 閲覧・編集画面のどちらでも、ボックスを押して完了表示を切り替えられます。切り替えた後は**Ctrl+S**で保存するとファイルに反映されます。
- 表で一部のセルを選択して削除したり文字を入力したりすると、区切り線（`|`）や表の形はそのまま残り、選択したセルの内容だけが消えるか書き換わります。ただし、表全体を選択するかCtrl+Aですべて選択して削除すると、通常の文字と同じように表自体が削除されます。

表の2行目（`---` の区切り行）は編集画面で直接修正できません。列の揃え位置は表ツールバーの揃えボタン（またはソース画面）で変更します。

表の両端の外側の `|` は省略しても同じ表として認識されます。セル内で `|` を入力すると表が崩れないよう自動的に `\|` として保存され、`コード` 内で入力した `|` はそのまま残りセルは分割されません。

- 直上がリストでない場合、表ツールバーのインデントボタンは無効になります。

## 9. タブとウィンドウ

| ショートカット | 動作 |
| --- | --- |
| Ctrl+W | タブを閉じる |
| Ctrl+Tab / Ctrl+Shift+Tab | 次のタブ / 前のタブ |

- 空のウィンドウがある場合は、新しく開かずにそのウィンドウで開きます。
- ウィンドウの位置・サイズと、表示・編集・言語の設定は、アプリを再起動したりアップデートしたりしてもそのまま維持されます。

## 10. 既知の制限

- 基本モードの編集画面では、**Alt+ドラッグ**による矩形選択は使えません。ライブモードや ![ソース](guide-btn-source.ja.png) **ソース**画面では使用できます。
