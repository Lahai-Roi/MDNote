# MDNote使用说明

本文按顶部菜单顺序介绍 MDNote 的菜单和界面。在文档中添加标题、列表、表格的方法，请参阅**帮助 → MD文件编写方法**。

## 1. 文件

| 菜单 | 快捷键 | 说明 |
| --- | --- | --- |
| 继续上一个会话 | | 开启后，关闭未保存的文档时不再提示，下次打开 MDNote 时原样恢复其内容。默认处于关闭状态。 |
| ![New](guide-new.png) 新建 | Ctrl+N, Ctrl+T | 打开新文档。 |
| ![Open](guide-open.png) 打开… | Ctrl+O | 打开 MD、TXT 文件。 |
| 指定编码打开… | | 文字出现乱码时，选择编码重新打开。 |
| 要恢复的文档… | | 恢复或删除未保存即关闭的文档。 |
| 最近的文件 | | 重新打开最近打开过的文档。 |
| ![保存](guide-save.png) 保存 | Ctrl+S | 保存当前文档。 |
| 另存为… | Ctrl+Shift+S | 选择新文件名和编码进行保存。 |
| 打印… | Ctrl+P | 打印文档。 |
| 退出 | Alt+F4 | 仅关闭当前窗口，其他窗口保持不变。 |

- 将文件拖放到窗口中，或在资源管理器中双击也可打开。
- 未保存的内容会在启动应用时询问是否恢复，并在通过**要恢复的文档…**（恢复所选、删除所选、稍后）手动恢复或删除前一直保留。
- **另存为**的编码可从 UTF-8、UTF-8(BOM)、UTF-16 LE、UTF-16 BE、ANSI(CP949) 中选择；以 Shift JIS、GBK、Big5、Windows-1252、UTF-32 LE/BE 打开的文档也可选择保持当前编码。如果包含 CP949 无法表示的字符，会提示使用 UTF-8 保存。
- 切换 MD 和 TXT 模式导致与文件扩展名不符时，保存时会建议使用符合当前模式的扩展名，以免覆盖原文件。
- 关闭未保存的文档时，可在**保存、放弃、取消**中选择。因 Windows 关机等原因同时关闭多个窗口时，点击**取消**将停止关闭其余窗口。

## 2. 编辑

| 菜单 | 快捷键 | 说明 |
| --- | --- | --- |
| ![edit](guide-btn-edit.zh-CN.png) 开始 / 结束编辑 | Ctrl+E | 在阅读界面和编辑界面之间切换。 |
| 始终以编辑模式打开 | | 开启后，打开文档即可直接编辑。 |
| ![txt](guide-btn-txt.png) TXT 模式 | | 将 MD 文档转换为纯文本或还原。 |
| 新文档默认使用 TXT 模式 | | 开启后，新文档将以 TXT 模式启动。 |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Y | 撤销或重新应用刚才的编辑操作。连续输入的文字（含退格键 Backspace）会一次性撤销；在移动光标、按 Delete、粘贴、剪切、执行命令、切换焦点或切换文档后输入的文字则会分为新的步骤。 |
| 全选 / 复制 / 剪切 | Ctrl+A / Ctrl+C / Ctrl+X | 选择全部内容，或复制、剪切所选文字。 |
| 粘贴 | Ctrl+V | 保留格式进行粘贴。 |
| 粘贴为纯文本 | Ctrl+Shift+V | 仅粘贴文字。 |
| 插入图片… | Ctrl+Shift+I | 插入图片。 |
| ![find](guide-find.png) 查找… | Ctrl+F | 查找文字。 |
| ![replace](guide-replace.png) 替换… | Ctrl+H | 查找并替换文字。 |

- **始终以编辑模式打开**处于开启状态（默认）时，文档会直接以编辑界面打开；关闭后则以**阅读**界面打开。在默认模式的编辑界面中，`#`、`**` 等符号会隐藏，直接以应用格式后的样式进行编辑。在**实时模式**（视图菜单）下，编辑界面中仅光标所在行和所选行会显示符号。
- 切换到 **TXT 模式**后，符号会被清除，仅保留可见文字，表格单元格之间用 Tab 分隔。将 TXT 切换回 MD 时，已有的符号不会突然变成格式。如果误操作切换，可按 Ctrl+Z 撤销。
- **粘贴**会保留粗体、斜体、删除线、链接以及单独指定的文字颜色。在 TXT 模式下始终仅粘贴文字。
- **插入图片**：用 Ctrl+V 粘贴复制的图片、粘贴或拖放图片文件，或通过“插入图片…”选择后，图片会立即显示。保存时会在文档旁创建同名文件夹（如 `笔记.md` → `笔记\`），仅将文档中保留的图片移入并更新链接。保存前删除的图片不会存入，已在该文件夹中的图片也不会重复复制。另存为时，会将文档使用的图片复制到新名称的文件夹中。
- 将图片文件拖放到编辑窗口中也可插入图片。
- 再次按下相同的快捷键即可关闭查找和替换。

## 3. 视图

| 菜单 | 快捷键 | 说明 |
| --- | --- | --- |
| 在新标签页中打开 | | 开启时文件在新标签页中打开，关闭时在新窗口中打开。 |
| 自动换行 | | 根据窗口宽度自动换行显示。 |
| 放大文字 / 缩小文字 | Ctrl++ / Ctrl+- | 也可使用 Ctrl+滚轮。 |
| 重置文字大小 | Ctrl+0 | 恢复为原始大小。 |
| 字体和大小… | | 设置默认字体和大小。 |
| 默认文字颜色… / 重置默认文字颜色 | | 设置或还原整个文档的默认颜色。 |
| ![dark](guide-btn-dark.png) 深色模式 | | 切换为深色界面。 |
| 行距 | | 可从 100、125、150、200% 和自定义中选择。 |
| Markdown 实时预览 | | 开启后，在编辑界面中仅将光标所在行和所选行显示为源文本（含符号）。关闭则为默认模式。 |

- 关闭**在新标签页中打开**的瞬间，已打开的标签页会分别拆分为新窗口。
- **自动换行**不会在文件中插入换行符。关闭后可通过横向滚动查看长行。
- 格式工具栏中的文字颜色仅应用于所选文字，与**默认文字颜色**互不影响。
- **行距**的初始默认值为 150%，同时适用于 MD 和 TXT。
- **默认模式**下整个文档以应用格式后的样式显示，光标所在行也会隐藏 `**`、`#` 等符号。首次运行时即为此模式。
- **实时视图**可在视图 → **Markdown 实时预览**中开启，开启后在编辑界面中仅将光标所在行和所选行显示为源文本（含符号）（阅读界面中始终仅显示应用格式后的样式），便于直接看着符号进行修改。初始状态为关闭（默认模式），更改后的模式在下次运行时仍会被记住。
- 视图设置仅改变屏幕显示，不影响文件内容。

## 7. 工具栏与界面

| 工具 | 位置 | 说明 |
| --- | --- | --- |
| 格式工具栏 | 菜单下方（编辑中） | 包含标题、文字样式、列表、待办、引用、代码、链接、图片、表格按钮。 |
| ![源码](guide-btn-source.zh-CN.png) 源码 | 格式工具栏最右侧 | 编辑直接显示符号和 HTML 标签的源码。 |
| ![txt](guide-btn-txt.png) TXT | 顶部 | 与编辑 → **TXT 模式**相同。 |
| ![outline](guide-outline.png) 大纲 | 右上角 | 显示标题列表，点击可跳转到对应标题。 |
| 表格工具栏 | 光标置于表格内时 | 包含左对齐、居中对齐、右对齐、添加和删除行/列、删除表格、在下方添加段落、缩进/减少缩进按钮。列对齐方式通过这些对齐按钮修改，而无需直接改动第二行（`---`）。 |

- 关闭**源码**后将返回应用格式的界面。
- 在 TXT 模式下，可进行显示行号的纯文本编辑。
- 大纲会连同 H1~H6 标记一起显示，拖动与正文之间的分隔线可调整宽度。

## 8. 输入时的操作

| 位置 | 按键 | 动作 |
| --- | --- | --- |
| 行首 | `-`、`*`、`+`、`1.` 后加一个半角空格或 Tab | 直接变成列表。（全角空格会被视为普通文字，不会变成列表。） |
| 列表 | Tab / Shift+Tab | 缩进或减少缩进一级。 |
| 空列表项 | Enter | 在同一级新增一个空列表项。 |
| 列表项行首 | Backspace | 按一次删除列表标记，按两次连同缩进一起删除。 |
| 有文字的复选框行 | Enter | 新增一行复选框。 |
| 粗体、斜体、删除线、行内代码内 | Enter | 在默认模式和实时模式下，换行后两行都会继续保持原有格式。 |
| 表格单元格内 | Home / End | 移动到该单元格的开头 / 结尾。 |
| 表格单元格内 | ↑ / ↓ | 在单元格内换行移动，在单元格最后一行按 ↓ 会移至下一行同一列的单元格。 |
| 表格内 | Tab / Shift+Tab | 移动到下一个或上一个单元格并选中该单元格的文字。在最后一行最后一个单元格按 Tab 会在下方新增一行。选中文字或单元格时按下，不会删除文字，而是直接移动到所选范围末尾的下一个单元格（Shift+Tab 为所选范围前的单元格）。 |
| 紧邻表格前或后 | Enter | 在表格外新增一个空行。 |
| 表格内 | Ctrl+] / Ctrl+[ | 将整个表格移入紧邻的上一列表项内，或移出到列表外。 |

- 若要结束待办清单，可在新生成的空复选框行按 **Backspace** 删掉复选框。
- 在阅读和编辑界面中，均可点击复选框切换完成状态。修改后需按 **Ctrl+S** 保存才会写入文件。
- 在表格中选中部分单元格并删除或输入文字时，分隔线（`|`）和表格外观保持不变，仅清除或替换所选单元格的内容。但如果选中整个表格或按 Ctrl+A 全选后删除，则会像普通文字一样将整个表格删掉。

表格的第二行（`---` 分隔线行）无法在编辑界面中直接修改。列对齐方式请通过表格工具栏的对齐按钮（或源码界面）修改。

表格左右两端外侧的 `|` 即使省略也会识别为同一个表格。在单元格内输入 `|` 时会自动保存为 `\|` 以免破坏表格，而在 `代码` 内输入的 `|` 会原样保留，不会拆分单元格。

- 如果表格紧邻的上方不是列表，表格工具栏中的缩进按钮会变灰。

## 9. 标签页与窗口

| 快捷键 | 动作 |
| --- | --- |
| Ctrl+W | 关闭标签页 |
| Ctrl+Tab / Ctrl+Shift+Tab | 下一个标签页 / 上一个标签页 |

- 如果已有空白窗口，则不会新建窗口，而是在该窗口中打开。
- 窗口位置、大小以及视图、编辑、语言设置，在重启或更新应用后仍会保持不变。

## 10. 已知限制

- 在默认模式的编辑界面中，无法使用 **Alt+拖动**进行矩形选择。在实时模式或 ![源码](guide-btn-source.zh-CN.png) **源码**界面中可以使用。
